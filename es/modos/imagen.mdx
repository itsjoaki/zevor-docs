El modo Imagen genera imágenes verticales 9:16 desde un prompt, o edita
a partir de imágenes de referencia.

## Variantes

| Variante | Qué aportas | Para qué |
| --- | --- | --- |
| **Texto a imagen** | Un prompt | Crear una imagen desde cero |
| **Imagen a imagen** | 1–3 referencias + prompt | Reinterpretar o combinar imágenes |

## Calidad

- **Lite** — rápido y barato para iterar.
- **Standard** — equilibrio para la mayoría de casos.
- **Pro** — máxima fidelidad y adherencia al prompt.

El coste en créditos depende de la calidad y se muestra antes de generar.

<Note>
  El límite de cada imagen de entrada es 5 MB. Si subes algo más grande,
  Zevor te avisa para que la reduzcas antes.
</Note>

## Consejos

- Las referencias mandan: si quieres conservar una cara o un estilo,
  adjunta una imagen clara de eso.
- Describe encuadre y luz, no solo el contenido.
